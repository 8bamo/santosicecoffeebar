# Santos ICE & COFFEE BAR

Statische Landingpage für Santos in Ludwigsburg.

## Dateien

- `index.html` - Seitenstruktur und Inhalte
- `styles.css` - Gestaltung und responsive Layouts
- `script.js` - frei für spätere Interaktionen

## Lokal testen

`index.html` direkt im Browser öffnen.

## GitHub

Wenn du das Repo lokal erst noch verbinden musst:

```bash
git init
git add .
git commit -m "Build initial Santos landing page"
git branch -M main
git remote add origin https://github.com/8bamo/santosicecoffeebar.git
git push -u origin main
```
